# Advanced Number Guessing Game

A Java-based number guessing game developed in Eclipse. This repository is also used for **Software Construction and Development (SCD) Lab 1** to practise Git and GitHub version-control operations.

## Project Details

- **Language:** Java
- **IDE:** Eclipse
- **Version Control:** Git and GitHub
- **Main source file:** `NumberGuessGame.java`

## Getting Started

### Requirements

- Java Development Kit (JDK)
- A terminal or command prompt (or Eclipse IDE)

### Run the program

1. Clone or download this repository.
2. Open the project in Eclipse, or open a terminal in the folder containing `NumberGuessGame.java`.
3. If the file is a standalone Java program, compile and run it with:

   ```bash
   javac NumberGuessGame.java
   java NumberGuessGame
   ```

   If your source file declares a package, or the project uses a different source-folder setup, run it through Eclipse or use the appropriate package/class path.

## SCD Lab 1: Git Operations

The following version-control operations were practised for this lab:

- **Commit:** Save a snapshot of changes in the local Git repository.
- **Push:** Upload local commits to GitHub.
- **Pull:** Retrieve and integrate changes from the remote repository.
- **Branching:** Create a separate line of development for code changes.
- **Pull request:** Compare and propose changes from the feature branch to `main`.
- **Merge:** Integrate the feature branch into `main` after reviewing the pull request.

### Common Git commands

```bash
git status
git add NumberGuessGame.java
git commit -m "Add or update Java number guessing game"
git push origin main
git pull origin main
git switch -c feature/lab1-merge
```

The branch and merge commands may vary depending on the current branch and whether a pull request has already been merged.
